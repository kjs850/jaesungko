# Y-Pay Map: 경기 재난 화폐 가맹점 지도

> 2020년 4월, 재난기본소득 지급 시작 직후 개인 프로젝트로 만들어 5일 만에 사용자 1,300명이 쓴 지도 서비스.

## 한 줄 요약

공공데이터와 코드 몇 줄로, 불편한 공식 가맹점 검색을 "지도에서 바로 보이는" 경험으로 바꿨습니다.

## 문제

2020년 4월 경기도가 재난기본소득을 지역화폐로 지급했습니다. 어디서 쓸 수 있는지 확인하려면 경기지역화폐 공식 사이트(gmoney.or.kr)의 가맹점 찾기를 써야 했는데,

- 시·군을 드롭다운에서 고르고 상호명을 입력해야 검색이 됨
- 결과가 표 형태라 "내 주변에 뭐가 있는지"를 알 수 없음
- 접속 폭주로 안내문("접속량이 많아 연결이 늦어지고 있습니다")이 뜨는 상태

## 해결

**y-pay.site**: 용인시 가맹점을 지도 위에 카테고리별 아이콘으로 표시하는 웹 지도.

- 상단에 식품 / 학원 / 의료 / 미용 / 식당 카테고리 필터
- 마커를 누르면 상호, 전화번호, 주소, 업종 표시
- 모바일 브라우저에서 바로 열리는 단일 페이지

## 만든 방법

| 구성 | 선택 | 이유 |
|---|---|---|
| 데이터 | 공공데이터포털(data.go.kr) 가맹점 데이터 → JSON | 무료, 공식 출처 |
| 프론트 | 정적 `index.html` + 지도 API | 서버 없이 동작 |
| 호스팅 | GitHub Pages (kjs850/ymap) | 무료, HTTPS 기본 |
| 도메인 | y-pay.site, 가비아 2,090원 | A 레코드 4개 + CNAME으로 GitHub Pages 연결 |
| 비용 | 도메인 2,090원 | 그 외 0원 |

핵심은 "빨리 내놓는 것"이었습니다. 서버, DB, 프레임워크 없이 정적 파일만으로 하루 안에 배포했습니다.

## 결과

**사용 지표** (2020.04.18 ~ 04.23, Google Analytics)

| 지표 | 값 |
|---|---|
| 사용자 | 1,334명 |
| 세션 | 1,600 |
| 페이지뷰 | 2,128 |

**사용자 반응**

- 페이스북 공유 게시물: 좋아요 101명, 댓글 25개, 공유 29회
- 사용자 메일: "이렇게 유용하고 사용편한 앱 개발해주셔서 너무 감사드립니다. 용인 친구들 보고 버그 제보해요." 실제로 누락 가맹점 제보가 메일로 들어옴
- 커뮤니티 댓글: "공대오빠들 또 매력발산 하시네요"

## 다음 단계

용인시 한 곳에서 경기도 전역으로 확장한 **경기지역화폐 지도 g-pay.info** 를 이어서 만들었습니다.

## 배운 것

> 코드 몇 줄이 남들에게 도움을 줄 수 있는 즐거움이 있다.

- 완성도보다 타이밍. 재난기본소득 지급 첫 주에 나왔기 때문에 쓰였습니다.
- 공공데이터 + 정적 호스팅 조합이면 개인이 비용 없이 공공 서비스의 빈틈을 메울 수 있습니다.
- 사용자가 직접 제보를 보내기 시작하면 서비스가 살아 있다는 신호입니다.
