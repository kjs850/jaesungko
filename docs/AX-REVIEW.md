# AX 소개 페이지 개편 검토

- 작업 브랜치: `codex/ax-consulting-profile`
- 검토일: 2026.10.11
- 상태: 로컬 구현·검증 완료, 배포 전

## 반영 내용

첫 화면의 메시지를 AX 문제 해결·구현·교육으로 변경했습니다. TMS 메시지 AI 기능, 후기 AI 요약, 콘텐츠 유통 플랫폼을 대표 업무 사례로 올렸습니다. 현업 문제·본인 역할·해결 방법·적용 상태를 구분하고, TMS 흐름을 설명용 도식으로 구성했습니다.

개인사업자·중소기업·공공 부문을 대상으로 협업 범위를 설명하고, 교육·강연·출판·심사·인터뷰 문의를 추가했습니다. 기존 발표 사진 두 장을 교육·대외 활동 영역에 배치했습니다. 테니스는 하단 개인 소개로 옮겼습니다.

사진 원본은 변경하지 않았습니다. 선택한 발표·강연·개인 사진만 `public/photos/`로 복사했습니다. 공개 제외로 적힌 상품·사내 화면과 해커톤 단체 사진은 포함하지 않았습니다.

Motion AI Kit의 공식 스킬·MCP 설정을 프로젝트에 설치했습니다. 업무 흐름을 4단계로 탐색하는 화면, 고민에 따른 협업 안내·메일 제목, 발표 사진 확대를 추가했습니다. 짧은 진입·전환 효과와 현재 섹션·읽기 진행 표시를 적용했습니다. 테니스는 기존 하단 위치를 유지합니다.

## 검증

- 실제 Chrome: 모바일 320·375px, 태블릿 768px, 데스크톱 1280px에서 가로 넘침 없음
- 메뉴의 섹션 이동, 업무 사례 상세의 클릭·Enter 열기/닫기 확인
- 교육 사진 로딩 확인. 로컬 이미지 5개와 앵커·상대 파일 링크 존재 검증
- `node --check scripts/export-profile.cjs`, `git diff --check` 통과
- 6쪽 A4 소개 PDF: 전체 페이지 렌더링을 확인, 내용 잘림과 한 줄만 남는 별도 페이지 제거
- 1200×630 공유 이미지 갱신·시각 확인
- 렌더링에 외부 CSS·스크립트·폰트 요청 없음
- `npm run check:profile`: Motion 로딩, 단계 선택·키보드 이동, 협업 안내, 사진 모달·Escape·포커스 복원, 현재 메뉴 표시 통과
- 320·375·768·1280px 모든 업무 단계에서 가로 넘침 없음
- 동작 줄이기 설정에서 애니메이션 없음, 인쇄 시 정적 흐름 도식 복원
- JavaScript 비활성화 시 사례·서비스·정적 도식·사진 원본 링크 사용 가능

## 공개 문구의 기준

- 사내 업무와 외부 컨설팅 실적 구분
- TMS 시범 운영·API 준비, 후기 요약 API 검증, 운영툴 연동 대기 상태 유지
- 업무 시간 절감률은 미측정이므로 사용하지 않음
- 이미지 보정 처리 시간 47초→13초는 모델별 3회 비교 측정임을 상세 설명에 명시. 전체 업무 효과와 구분
- 공개 여부 최종 확인이 남은 비용·모델명·원본 상품 화면은 사용하지 않음
- 삼성전자 강연의 월 차이는 확인 대기, 사이트에는 2019년만 표기
- 리딩 종료월은 최신 입력의 2025.05를 반영하고 ‘약 5년’으로 표시
- 실제 집필·심사·인터뷰 경력이 있다고 표현하지 않고 제안받는 활동으로 소개

- 운영툴 연동 후 상태와 업무 효과 수치
- 공개 가능한 상품 화면 또는 설명용 재구성 화면
- 확정한 교육 과정·실습 결과물과 추가 발표 자료
- 삼성전자 강연 월 확인
