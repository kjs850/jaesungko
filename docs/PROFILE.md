### 카카오메이커스 메시지 문구·이미지 AI 기능

- 시기: 2026.08부터
- 문제: 상품마다 마케팅 문구와 발송 이미지를 준비하고, 발송 유형별 규칙을 반복 검수. 개인 프롬프트의 결과를 공유·검증하기 어려움
- 본인 역할: 현업 인터뷰, 업무 단계 정리, 화면·워크플로우·API 설계·구현, 배포, 품질 피드백 반영, 운영 모니터링. 동료의 초기 화면 프로토타입을 이어받아 실사용 수준으로 전환
- 해결: 상품과 요청 입력 → 문구·이미지 후보 생성 → 담당자 선택·수정 → 발송용 결과물. 형식·개수 등의 규칙을 프로그램에서 확인하고, 일부 후보 실패 시 다른 결과는 유지
- 구현: 메시지 생성·이미지 보정·연동 API
- 사람의 역할: 상품 선택, 최종 검수와 수정, 발송
- 효과: 작성·보정·미리보기·다운로드를 한 흐름으로 구성. 업무 시간 절감 효과는 아직 측정하지 않았음
- 공개 자료: 실제 상품 화면 대신 업무 흐름을 재구성한 설명용 도식
- 성능 근거: 이미지 보정 1장 약 47초에서 약 13초로 개선, 2026.09.09 모델별 3회 비교 측정. 전체 업무 처리 시간 개선율과 구분

### 카카오메이커스 상품 후기 AI 요약

- 시기: 2026.07~09
- 문제: 쌓인 후기를 읽는 부담, 화면 프로토타입에서 실제 업무 연동으로 전환 필요
- 본인 역할: 요구사항과 프롬프트 개선, 모델 선정, 품질 평가, API 서버 구현·배포, 인수인계
- 해결: 요약을 원본과 대조하는 별도 평가, 후기가 바뀔 때만 재생성하는 캐시, 운영툴용 요약·피드백 API
- 구현: 후기 요약·품질 평가 API, 배포·연동 검증

### 카카오 콘텐츠 유통·분류 플랫폼

- 문제: 서비스별로 나뉜 콘텐츠 운영, 수작업 분류, 필터 증가에 따른 성능 저하, 처리 경로 추적의 어려움
- 본인 역할: 초기 설계·구축·운영, 이후 개발 리딩
- 해결: 수집·전처리·분류·유통 흐름 통합. 규칙·ML·LLM으로 분류와 품질 관리, 변경 이력과 데이터 흐름 추적
- 결과: 전사 콘텐츠 유통 플랫폼과 운영 도구 구축, 분류 자동화와 운영 이력 관리
- 정량 성과는 확인되지 않아 공개 페이지에 추가하지 않음
