# 프로필 페이지 구축 플랜

> 목표: `docs/PROFILE.md` 내용을 기반으로 신뢰감 있는 1-page 프로필 사이트를 Vercel에 배포한다.

## 1. 결정 사항

| 항목 | 결정 | 이유 |
|---|---|---|
| 스택 | **정적 HTML + CSS 1개 파일** (`index.html`) | 1페이지 정적 콘텐츠. 프레임워크·빌드 불필요. Vercel이 그대로 서빙 |
| 학력 | **미노출** | 2008년 졸업으로 오래되어 최근 커리어 강조 방침과 맞지 않음 |
| 콘텐츠 소스 | `docs/PROFILE.md`가 정본. HTML은 여기서 수동 반영 | 빈도 낮은 수정. 빌드 파이프라인 도입은 과함 |
| 프로필 사진 | `public/profile.jpg` 640×640 JPEG | 원본 1294×1031 → 중앙 정방형 크롭 |
| 폰트 | Pretendard (CDN) + 시스템 폰트 fallback | 한글 가독성, 무료 |
| 다크모드 | `prefers-color-scheme` CSS만 | JS 토글 불필요 |
| 분석/폼/CMS | 없음 | YAGNI |

## 2. 디자인 원칙 (신뢰 주는 페이지)

> **2026-09-07 디자인 리뷰(design-taste-frontend) 반영 완료.**
> 디자인 리드: trust-first 개발자 프로필, 독자는 채용 담당자·협업 제안자. 다이얼 `VARIANCE 5 / MOTION 3 / DENSITY 3`.
> - 전각 대시·중간점 남용 제거, 대문자 트래킹 아이브로우 제거(섹션 제목은 한글 일반체)
> - 텍스트 전용 카드 11개 → 헤어라인 구분 리스트로 교체. 카드는 실서비스 캡처 4장에만 사용
> - 히어로: 이름 / 직함 / 한 줄 소개 / CTA 1개(이메일) + 사진(220px, 12px 라운드). 해시태그 필 제거
> - 지표 3개(18년 / 5년 리더 / 4개 운영 서비스)는 박스 없이 숫자 + 헤어라인
> - 2008~2010 경력은 `<details>`로 접어 최근 커리어 강조
> - 라운드 12px 단일, 액센트 네이비 `#1e3a5f` 단일, 라이트 기본 + 시스템 다크 자동
> - 이미지: `public/profile.jpg`(640²), `public/shots/*.jpg`(운영 사이트 캡처, 960px)

- **절제**: 흰/오프화이트 배경, 검정 텍스트, 포인트 컬러 1개(네이비 or 카카오 옐로우 계열 중 하나만). 그라디언트·애니메이션 없음.
- **위계**: 이름 → 직함/소속 → 한 줄 소개 → 핵심 이력 → 상세 경력 순서. 스크롤 없이 첫 화면에서 "누구인지" 파악 가능.
- **최근 커리어 강조**: 상단 지표 타일은 현재 직무(FDE·AX/DX), AI 기능 적용 수, 리더 5년, 경력 18년으로 구성. 2014년 이전 성과 수치(장애 30% 단축, 반응률 20%)는 타일에서 제외하고 경력 본문에만 유지.
- **외부 증거**: if(kakao) 발표 영상/자료 링크를 눈에 띄게 배치. 실제 발표 링크가 신뢰의 핵심.
- **사진**: 원형 or 라운드 사각, 이름 옆 상단 고정. 배경 단색, 정면 사진.
- **인쇄 대응**: `@media print`로 A4 1장 PDF 출력 가능 (이력서 대체용).
