# AX 전문가 소개 페이지 구성

## 목적과 구현

개인사업자·중소기업·국가기관 등 공공 부문의 AX 문제 해결, 직접 구현, 교육 문의를 받는 전문가 소개 페이지. 출판·심사·인터뷰 제안도 받을 수 있도록 구성합니다.

- 정적 `index.html`과 로컬 CSS·JavaScript, 별도 프레임워크·빌드 없음
- 공개용 콘텐츠 정본: `docs/PROFILE.md`
- 원본 답변·사진: `docs/ax-consulting-input/` (Git·배포 제외)
- 기존 따뜻한 종이색·테라코타 강조색·프로필 사진 유지
- 시스템 글꼴 사용, 페이지 렌더링에 외부 CDN·스크립트 요청 없음
- Motion 기반 짧은 진입 효과, 업무 흐름 탐색, 협업 선택 안내, 사진 확대 적용. 설정·검증은 `docs/MOTION.md` 참고
- 메일 링크만 사용. 별도 폼·분석·CMS 없음

## 페이지 순서

1. 첫 화면: AX 전문가 소개, 사례·문의 CTA, 18년 경력·약 5년 리딩·현재 FDE 역할
2. 업무 사례: TMS 문구·이미지 → 후기 요약 → 콘텐츠 유통 플랫폼
3. 협업 범위: AX 자문 / 구현·자동화 / 교육·워크숍, 대상별 설명
4. 일하는 방식: 듣기 → 검증 → 연결 → 전달
5. 교육·대외 활동: 실제 발표·강연 사진과 링크, 협의 가능한 교육 주제, 출판·심사·인터뷰 제안
6. 경험의 바탕: 경력, 접을 수 있는 이전 경력, 간결한 기술 목록, PDF
7. 개인 소개·제품: 테니스 사진, ytcc.info 대표 제품, 나머지 제품의 짧은 링크
8. 문의: AX 문제 해결·구현 / 교육 / 대외 활동 목적별 이메일

## 근거와 표현

- 현재 카카오 재직과 평일 저녁·주말 협의 상태 표기
- 사내 업무 사례를 외부 컨설팅 실적으로 표현하지 않음
- 최신 사용자 요청에 따라 완료한 구현과 본인 역할 중심으로 소개. 상태 배지와 대기·측정 예정 안내 제외
- 업무 시간·매출·비용 절감률 등 미확인 효과를 공개 문구에 넣지 않음
- 실제 상품명·상품 이미지·내부 화면을 공개용으로 복사하지 않음. TMS는 설명용 흐름 도식으로 구성
- if(kakao) 2018·삼성전자 2019 사진은 기존 개발 발표의 근거로 사용
- 삼성전자 강연 월은 자료가 달라 연도만 표기
- 콘텐츠 플랫폼 리딩 종료월은 최신 작성 답변의 2025.05 반영
- 내부 화면·동료가 함께 나온 해커톤 원본은 이번 공개용 자산에 포함하지 않음

## 자산과 내보내기

- `public/profile.jpg`: 기존 프로필
- `public/photos/ifkakao-2018.jpg`, `samsung-talk-2019.jpg`: 발표·강연
- `public/photos/tennis-2025.png`: 하단 개인 소개
- `public/jaesung-ko-profile.pdf`: 페이지의 인쇄 스타일로 생성한 소개 자료
- `public/og-profile.png`: AX 메시지로 갱신한 1200×630 공유 이미지
- `scripts/export-profile.cjs`: 로컬 시스템 글꼴·이미지가 준비되면 PDF·OG 생성. 상대 링크를 공개 URL로 변환

실행 방법은 `docs/EXPORT.md`에 있습니다. 배포 시 HTML·사진·PDF·OG를 함께 반영합니다.

## 간결한 소개 구성으로 갱신

첫 방문자가 빠르게 훑도록 사례는 요약, 서비스는 한 문장, 경력은 네 줄로 표시합니다. 진행 상태 배지를 제거하고 업무 흐름·전체 경력은 펼쳐보기로 제공합니다. 별도의 일하는 방식·대상별 설명을 줄이고 교육·대외 활동은 실제 사진과 제안 안내로 정리합니다. 상세 업무 근거는 `docs/PROFILE.md`에 유지하며 PDF에는 요약만 담습니다.
